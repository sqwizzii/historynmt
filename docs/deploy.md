# Як опублікувати сайт в інтернеті

Результат: сайт за адресою на кшталт `https://history.вашдомен.com` з HTTPS, який працює постійно.
Що потрібно: орендований сервер (VPS) і домен. Разом це приблизно 5-10 євро на місяць.

## 1. Купіть домен
У будь-якого реєстратора (Namecheap, Porkbun, Cloudflare, ukraine.com.ua). Підійде і піддомен існуючого домену.

## 2. Орендуйте сервер
Hetzner Cloud (CX22, ~4 євро/міс), DigitalOcean або схожий VPS:
- ОС: Ubuntu 24.04
- 2 vCPU, 4 ГБ RAM (мінімум 2 ГБ)
- Запишіть IP-адресу сервера

## 3. Спрямуйте домен на сервер
У DNS домену додайте запис `A`: ім'я `history` (або `@`) -> IP сервера. Поширення займає від кількох хвилин до години.
Якщо домен у Cloudflare, поставте режим "DNS only" (сіра хмарка), поки Caddy не отримає сертифікат.

## 4. Налаштуйте сервер
```bash
ssh root@IP_СЕРВЕРА
curl -fsSL https://get.docker.com | sh
ufw allow OpenSSH && ufw allow 80 && ufw allow 443 && ufw --force enable
```

## 5. Завантажте проєкт і запустіть
```bash
git clone <адреса вашого git-репозиторію> nmt && cd nmt
./scripts/make-env.sh history.вашдомен.com
docker compose up -d --build
```
Скрипт створить `.env` із випадковими секретами та покаже пароль вчителя (логін `teacher`).
Перша збірка триває кілька хвилин. Далі відкрийте `https://history.вашдомен.com`: Caddy сам отримає HTTPS-сертифікат.

## 6. Перший вхід
1. Увійдіть як `teacher` із паролем зі скрипта.
2. Змініть пароль у профілі.
3. У панелі вчителя задайте код запрошення, який вчителька роздасть учням.

## Оновлення сайту
```bash
cd nmt && git pull && docker compose up -d --build
```

## Резервні копії
Щоночі через cron (`crontab -e`):
```
0 3 * * * /root/nmt/scripts/backup.sh
```
Копії лежать у `backups/`; періодично забирайте їх за межі сервера (або ввімкніть бекапи сервера в панелі хостингу).

## Якщо щось не працює
- `docker compose ps` показує стан контейнерів, `docker compose logs backend` або `logs caddy` покаже помилки.
- Сертифікат не видається: перевірте, що DNS вже вказує на сервер і порти 80/443 відкриті.
- Білий екран після оновлення: оновіть сторінку з Ctrl+Shift+R.

> Файли розгортання ще не запускалися на реальному сервері, тому перший запуск краще робити без поспіху і дивитися логи.
