# Безкоштовний провайдер ШІ для пояснень помилок

Платформа викликає будь-який OpenAI-сумісний `…/chat/completions`. Без `AI_API_KEY` пояснення просто недоступні («тимчасово недоступне» + кнопка «Повторити»), а тести, бали й результати працюють як завжди. Платний API не потрібен і не підключений.

## Змінні середовища

| Змінна | Значення |
|---|---|
| `AI_API_KEY` | ключ провайдера (обов'язкова, лише в панелі хостингу або в локальному `config/application.yml`, поза Git; у фронтенд ніколи не потрапляє) |
| `AI_BASE_URL` | адреса API (без `/chat/completions`) |
| `AI_MODEL` | назва моделі |
| `AI_MAX_TOKENS` | ліміт довжини відповіді, за замовчуванням 1000 (моделі з «мисленням» витрачають токени й на міркування) |
| `AI_REASONING_EFFORT` | необов'язково, `low`/`medium`/`high`; для Gemini задайте `low`. Порожнє: параметр не надсилається (деякі провайдери відхиляють невідомі параметри) |
| `AI_TIMEOUT_SECONDS` | тайм-аут запиту, за замовчуванням 25 |
| `AI_HOURLY_LIMIT_PER_USER` | нових генерацій на користувача за годину (за замовчуванням 40) |

Додатково платформа сама обмежує витрати: пояснення створюється лише для неправильної відповіді, зберігається в БД і повторно використовується для того самого питання та тієї самої помилки, відповідь обмежена 300 токенами, а в запит не передаються дані учнів.

## Варіант A: Groq

Перевірено за [console.groq.com/docs/rate-limits](https://console.groq.com/docs/rate-limits) на момент підготовки.

1. Зареєструйтеся на [console.groq.com](https://console.groq.com), відкрийте **API Keys → Create API Key**, скопіюйте ключ (показується один раз).
2. Змінні:
   - `AI_BASE_URL=https://api.groq.com/openai/v1`
   - `AI_MODEL=openai/gpt-oss-20b` (є в таблиці лімітів; перелік моделей дивіться у своєму акаунті)
   - `AI_API_KEY=<ваш ключ>`
3. Базові ліміти для `openai/gpt-oss-20b` за документацією: 30 запитів на хвилину, 1000 на добу, 8 тис. токенів на хвилину, 200 тис. токенів на добу. Ліміти діють на всю організацію (не на окремого учня); точні значення для вашого акаунту дивіться на сторінці Limits у консолі. Після перевищення API повертає 429, а платформа показує «тимчасово недоступне».
4. Умови використання даних і доступні плани перевірте в політиці Groq самостійно: я їх не перевіряв.

## Варіант B: Google Gemini API (безкоштовний рівень)

Перевірено за [ai.google.dev/gemini-api/docs/pricing](https://ai.google.dev/gemini-api/docs/pricing) і [ai.google.dev/gemini-api/docs/openai](https://ai.google.dev/gemini-api/docs/openai).

1. У [Google AI Studio](https://aistudio.google.com) створіть API-ключ (**Get API key**).
2. Змінні:
   - `AI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai`
   - `AI_MODEL=` назва моделі з вашого переліку в AI Studio, у якої вказаний безкоштовний рівень. Документація показує приклад `gemini-3.8-flash`, але доступність у free tier перевірте на сторінці цін.
   - `AI_API_KEY=<ваш ключ>`
   - `AI_REASONING_EFFORT=low` (за документацією Gemini; без нього моделі з «мисленням» можуть витратити весь ліміт токенів на міркування й повернути порожню відповідь)
3. Ліміти безкоштовного рівня залежать від моделі й змінюються, тому їх подано не тут, а в AI Studio (**Rate limits**) і на сторінці цін.
4. **Конфіденційність:** на безкоштовному рівні, за сторінкою цін, вміст запитів може використовуватися для покращення продуктів Google. Платформа не надсилає персональних даних учнів, але текст питань вчителя піде до Google. Якщо це неприйнятно, використовуйте інший варіант.
5. Якщо пояснення порожні або обрізані, збільште `AI_MAX_TOKENS` і задайте `AI_REASONING_EFFORT=low`.

## Налаштування

- **Render:** Environment → додайте змінні → збережіть (сервіс перезапуститься).
- **Локально:** у `config/application.yml` (файл у `.gitignore`):
  ```yaml
  app:
    ai:
      api-key: <ваш ключ>
      base-url: https://api.groq.com/openai/v1
      model: openai/gpt-oss-20b
  ```

## Перевірка

1. Створіть тест з режимом «Після завершення тесту», пройдіть його, відповівши неправильно.
2. У розборі результату під помилкою має з'явитися блок «Пояснення згенеровано ШІ». Повторне відкриття сторінки не викликає ШІ вдруге (пояснення береться з БД).
3. Без ключа або при вичерпаному ліміті з'являється повідомлення «тимчасово недоступне» з кнопкою «Повторити»; результат тесту не страждає.

## Діагностика: «Пояснення від ШІ тимчасово недоступне»

Користувач бачить загальне повідомлення, а точну причину сервер пише в лог. У Render → **Logs** знайдіть рядок `ШІ-провайдер: помилка` (ключ і заголовок Authorization у логах не з'являються). Під час старту є рядок із endpoint, моделлю й параметрами.

| `category` | Що означає | Що перевірити |
|---|---|---|
| `AUTH` (401/403) | ключ недійсний або немає доступу | `AI_API_KEY`: без лапок і пробілів, ключ чинний у AI Studio |
| `NOT_FOUND` (404) | неправильна модель або адреса | `AI_MODEL` (точна назва), `AI_BASE_URL` |
| `RATE_LIMITED` (429) | вичерпано ліміт безкоштовного рівня | зачекайте або зменште навантаження |
| `BAD_REQUEST` (400) | провайдер відхилив параметри | у повідомленні провайдера видно поле; перевірте `AI_REASONING_EFFORT`, `AI_MAX_TOKENS` |
| `TRUNCATED` | модель витратила ліміт токенів на «мислення» | `AI_REASONING_EFFORT=low`, збільшіть `AI_MAX_TOKENS` |
| `TIMEOUT` | відповідь надто повільна | збільште `AI_TIMEOUT_SECONDS` |
| `BAD_RESPONSE` | незвичний формат відповіді | `AI_BASE_URL` має бути OpenAI-сумісною |
| `NETWORK` / `SERVER_ERROR` | мережа чи збій провайдера | повторіть пізніше |

Якщо в лозі взагалі немає цього рядка й під час старту написано «ШІ-пояснення вимкнено», змінна `AI_API_KEY` не дійшла до сервісу (перевірте Environment і перезапуск).
