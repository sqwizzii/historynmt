# Brag plan: НМТ / Історія

Кут: чорно-біла мінімалістична платформа для підготовки до НМТ, 21.5 с, 1920x1080, 30 fps.
Тон: default (чіткий, динамічний), стиль збігається з сайтом: Oswald, чорно-біла сітка.

Розкадровка:
1. 0-3 с, хук: «Знай історію. Складай НМТ.» на чорній сітці.
2. 3-7 с: головна сторінка справжнього застосунку, «Усе для НМТ в одному місці».
3. 7-11.5 с: тест із таймером, курсор обирає відповідь.
4. 11.5-15.5 с: картка, що перевертається.
5. 15.5-18.5 с: демо-результат 178/200 (орієнтовно) і теми, «Робота над помилками».
6. 18.5-21.5 с: «НМТ / Історія», тести, картки, помилки, реєстрація за кодом від вчителя.

Кадри інтерфейсу зроблено зі справжнього застосунку; дані (назви тестів, питання, ім'я «olena») вигадані.
Музика й ефекти синтезовані в `work/audio.py`; кадри збираються з `work/index.html` скриптом `work/render.mjs`.
